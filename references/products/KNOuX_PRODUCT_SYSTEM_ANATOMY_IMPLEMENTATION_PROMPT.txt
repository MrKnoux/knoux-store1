INTERACTION — REQUIRED

IDLE
- subtle deterministic field motion
- slow bounded camera drift
- no selected detail

HOVER
- restrained halo/scale
- local path highlight
- pointer cursor
- no essential information available only on hover

SELECT
- selected node becomes dominant
- unrelated geometry dims
- related pathways brighten
- camera reframes smoothly toward the selected node
- real detail panel changes to selected node
- optional travelling relation signal may connect to one verified related node

CLEAR
- Escape clears selection
- explicit clear/back control
- camera returns to neutral after a short delay

Do not use fake narration.

PICKING

Implement reliable screen-space node picking.

Use stable pixel hit radii by form factor:
- desktop smaller
- tablet larger
- mobile largest

Distinguish drag from click/tap using a movement threshold.

Desktop:
- drag to orbit
- damping
- bounded polar angle
- no pan
- do not let wheel zoom trap normal page scroll

Touch:
- preserve vertical scroll
- tap selects
- no hover assumptions

Keyboard:
- mirror every node in a semantic DOM index
- visible focus
- Enter/Space selects
- Escape clears

CAMERA / SELECTION

When a node is selected:
- compute a bounded framing target
- ease camera toward that target
- never allow the panel and selected node to collide badly
- preserve readable negative space for the information panel
- on mobile, prefer panel below the scene instead of side-by-side

When the user manually orbits:
- cancel automatic reframing control temporarily
- record the resulting camera state
- resume idle drift only after inactivity

Do not implement aggressive camera jumps.
