# Vaultex interaction study closure

The local HTML is a motion-mechanics reference only. KNOuX uses its existing reveal groups, section staging, pointer response and contextual focus across Home, About, Work, Engineering, Solutions and the division/product routes. The new Home field uses focus/hover/scroll activation; About mounts the Living Mark near view; the Companion uses a single demand-driven pointer loop.

Rejected source elements: the yellow identity, typefaces and branding; a hidden native cursor and infinity cursor; fabricated catalogue/metrics; full-page smooth-scroll ownership; third-party model iframe; and the runtime Lenis, GSAP, anime, Three CDN and Google Fonts imports. None of those dependencies is added to production code.

Motion contracts: semantic content stays in DOM; reduced-motion styles and component checks remain authoritative; WebGL components cap DPR and stop or reduce when offscreen/hidden; no branded layout uses `Math.random()`. This note records code architecture. Route-by-route visual and performance outcomes require the browser QA evidence from this sprint, not inference from the reference HTML.
