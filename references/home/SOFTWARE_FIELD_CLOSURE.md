# Home Software Field

The old second-block `UniverseConstellation` is retained in source, while the existing `/products` `ProductUniverse` discovery surface remains unchanged. Home now reads the seven real `softwareProducts` as an asymmetric identity field and scrolling editorial records. Each record links to its current `/products/[slug]` dossier. Focus, hover and scroll visibility select the contextual preview; the record links remain fully useful if scripting or motion is absent.

The preview uses the existing deterministic `DeterministicSignature`, real product code, family, tagline, status and platform. The authenticated preview showed that the initial two-column presentation read too much like an ordinary index beside the accepted Hero. The closure revision layers a faint canonical mark and oversized system serial behind the signature, and turns the seven links into an illuminated typographic sequence. Those marks are decorative and pointer-transparent; the real dossier links and focus behavior remain intact.

It does not create separate project data, metrics, client cases or an additional WebGL context. On narrow screens the preview precedes the complete record list in normal document flow. The local production build showed no page overflow at 390×844 and no clipped identity caption at 1280×720. The revised Vercel preview still needs visual confirmation after deployment.

The field survived the branch reconciliation that merged local `4cc1e35` with remote `61ddcb1` at `9586f2c`. That merge added 162 `globals.css` lines to this presentation and kept the `HomeSoftwareField` serial, the canonical-mark emblem and the `data-serial` record attribute, while also taking the Sentinel surface from the other side. `HomeSoftwareField.tsx` differs from `61ddcb1` only by those four closure additions, so the accepted revision is intact at the merged HEAD and was not redesigned again.
